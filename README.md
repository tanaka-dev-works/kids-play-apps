# ぽんぽんプレイ 🎈🥁🫧

3歳の娘のために作った、ブラウザで動くミニアプリ集です。
インストール不要・HTMLファイルを開くだけで遊べます。

## あそびかた

遊びたいアプリのフォルダにある `index.html` をダウンロードして、ブラウザ（Chrome / Edge / Safari など）で開くだけ。
マウスでもタッチ操作でも遊べます。

| アプリ | フォルダ | あそびかた |
|--------|----------|------------|
| 🫧 おえかきバブル | [`apps/oekaki-bubble/`](apps/oekaki-bubble/) | 画面をなぞると虹色の跡と泡が生まれる。泡をタップすると「ぽんっ」とキラキラが散る |
| 🥁 たいこをたたけ！ | [`apps/taiko/`](apps/taiko/) | 太鼓をタップすると「ドン！」と音が鳴って波紋と星が飛び散る。たたくほど盛り上がる |
| 🎈 ふうせんとばせ | [`apps/fuusen/`](apps/fuusen/) | タップで風船を空高く飛ばそう。雲を抜けて星空まで行くとお祝い演出！ |
| ☂ かさをひらいて | [`apps/kasa-wo-hirate/`](apps/kasa-wo-hirate/) | 指やマウスでかさを動かすと、ふってくる雨がかさに当たってはじける |
| 🔦 くらい うみの たんけん | [`apps/kurai-umi/`](apps/kurai-umi/) | 潜水艦のライトで暗い海を照らして、深さ4000mまでの生きもの32種類を探す。見つけると名前を読み上げて図鑑に集まる（[くわしく](apps/kurai-umi/README.md)） |

## フォルダ構成

```
README.md            … この説明
apps/
  <アプリ名>/
    index.html       … アプリ本体（1ファイルで完結）
    README.md        … くわしい説明（あるアプリのみ）
```

## とくちょう

- **失敗がない** — どう触っても楽しい結果になる設計
- **文字が読めなくてもOK** — 操作はタッチ・なぞるだけ。ボタンはひらがな表記
- **すぐ反応する** — 触れた瞬間に色・音・アニメーションが起きる
- **1ファイル完結** — ライブラリ不要、HTML + Canvas API + Web Audio API のみ

## 動作環境

- モダンブラウザ（Chrome / Edge / Firefox / Safari）
- PC・タブレット・スマートフォン対応
- オフラインでも動作します
