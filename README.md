# ぽんぽんプレイ 🎈🥁🫧

3歳の娘のために作った、ブラウザで動くミニアプリ集です。
インストール不要・HTMLファイルを開くだけで遊べます。

## あそびかた

各HTMLファイルをダウンロードして、ブラウザ（Chrome / Edge / Safari など）で開くだけ。
マウスでもタッチ操作でも遊べます。

| アプリ | ファイル | あそびかた |
|--------|----------|------------|
| 🫧 おえかきバブル | `oekaki-bubble.html` | 画面をなぞると虹色の跡と泡が生まれる。泡をタップすると「ぽんっ」とキラキラが散る |
| 🥁 たいこをたたけ！ | `taiko.html` | 太鼓をタップすると「ドン！」と音が鳴って波紋と星が飛び散る。たたくほど盛り上がる |
| 🎈 ふうせんとばせ | `fuusen.html` | タップで風船を空高く飛ばそう。雲を抜けて星空まで行くとお祝い演出！ |

## とくちょう

- **失敗がない** — どう触っても楽しい結果になる設計
- **文字が読めなくてもOK** — 操作はタッチ・なぞるだけ。ボタンはひらがな表記
- **すぐ反応する** — 触れた瞬間に色・音・アニメーションが起きる
- **1ファイル完結** — ライブラリ不要、HTML + Canvas API + Web Audio API のみ

## 動作環境

- モダンブラウザ（Chrome / Edge / Firefox / Safari）
- PC・タブレット・スマートフォン対応
- オフラインでも動作します
