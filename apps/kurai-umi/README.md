# くらい うみの たんけん

4〜8歳向けのブラウザ遊びです。潜水艦のライトで暗い海を照らしながら、深さ4000mまで潜って生きものを探します。見つけた生きものは図鑑に集まります。

HTMLファイル1つで動きます。ダブルクリックしてブラウザで開けば、ネットにつながっていなくても遊べます。

## あそびかた

| そうさ | なにが おきる |
|---|---|
| マウスを動かす | 潜水艦がついてきて、まわりが明るくなる |
| マウスを画面の下の端に置く | 深く潜る。置き続けると だんだん速くなる |
| マウスを画面の上の端に置く | 浮かび上がる |
| クリック・好きなキー | 泡が出る。近くの魚が泡を追いかける |
| 矢印キー・マウスホイール | 潜水艦を動かす・潜る |
| 海の底(4000m)の宝箱をクリック | 図鑑が開く |
| 右上のパレットボタン | 潜水艦の色とライトの色を変える |
| 右上のスピーカーボタン | 音の大きさを「普通・小さめ・消音」で切り替える |

字が読めなくても遊べるように、画面には説明文をほとんど出していません。

## 中身

### 生きもの(32種類)

本物がすんでいる深さに、だいたい合わせて置いています。★は、ときどき画面を横切る生きものです。

| 深さ | 生きもの |
|---|---|
| 0〜200m | さかな、くまのみ、たつのおとしご、うみがめ、ひとで、ちんあなご、かに、ふぐ、たこ、★いるか、★まんた、★じんべえざめ |
| 200〜1000m | くらげ、ほたるいか、たかあしがに、しーらかんす、でめにぎす、こうもりだこ、めんだこ、★りゅうぐうのつかい、★くじら、★だいおういか、★みつくりざめ、★らぶか |
| 1000〜3000m | ちょうちんあんこう、おにきんめ、だいおうぐそくむし、ぺりかんうなぎ、とかげぎす |
| 3000〜4000m | せんじゅなまこ、ながづええそ、★りばいあさん(想像上の生きもの) |

ライトを当てると、種類ごとに反応が変わります。ふぐはふくらみ、ちんあなごは砂にもぐり、みつくりざめはあごが前に飛び出し、こうもりだこはマントをかぶって丸まります。

### 毎回ちがう海

- 生きものの数と場所は、遊ぶたびに変わります。
- ★の生きものは、7〜15秒ごとに、今いる深さにすむものから1種類が選ばれて通りかかります。りばいあさんは2400mより深いところで、3回に1回くらいしか出ません。
- 毎回3匹以上が「きらきら」になります。色がにじ色に変わり、まわりに光のつぶが出ます。見つけると図鑑のカードに★がつきます。

### 読み上げ

初めて見つけた生きものの名前を「めんだこ を みつけたよ!」と読み上げます。図鑑のカードを押しても名前を読みます。ブラウザの読み上げ機能(Web Speech API)を使うので、パソコンに日本語の音声が入っていないと声は出ません。

### 保存されるもの

図鑑の記録と潜水艦の色は、ブラウザの中(localStorage)に保存されます。同じブラウザで開けば続きから遊べます。サーバーには何も送りません。

## おうちの方へ

- スタートボタンを押すと全画面になります。Escキーで全画面が終わります。Chrome・Edgeでは、Escキーを長押しします(子どもが押しても抜けにくくするため)。
- 音は「小さめ」で始まります。
- 広告・外部リンク・課金・個人情報の入力はありません。
- 激しい点滅はありません。パソコンの設定でアニメーションを減らすようにしていると、動きを少し控えめにします。

## 動作環境

Chrome・Edgeの最新版で確認しています。Firefox・Safariでも動く作りですが、未確認です。タッチ操作(タブレット)にも対応しています。

## 技術メモ

- `index.html` 1ファイルに、HTML・CSS・JavaScriptがすべて入っています。
- 画像や音声のファイルは使っていません。絵はCanvasで、音はWeb Audio APIで、その場で作っています。
- 外から読み込むのは、タイトルなどの文字の見た目(Google FontsのZen Maru Gothic)だけです。読み込めないときは、パソコンに入っているフォントで表示されます。
