# ぐるぐる うちゅう

4〜8歳向けのブラウザ遊びです。太陽のまわりを押すと惑星が生まれて回りだし、真上を通るたびに音が鳴ります。置けば置くほど、宇宙がオルゴールになります。

HTMLファイル1つで動きます。ブラウザで開けば、ネットにつながっていなくても遊べます。

## あそびかた

| そうさ | なにが おきる |
|---|---|
| 空いているところを押す | 惑星が生まれる。長く押すほど大きくなる |
| 惑星を短く押す | 月がふえる(3つまで) |
| 惑星をドラッグ | 別の場所へ動かす。別の惑星に重ねると合体する |
| 惑星を長押し | 「のってみる」。カメラがその惑星を追いかける |
| 太陽を押す | 太陽フレア。全部の惑星が光って和音が鳴る |
| 太陽を5回つづけて押す | 超新星になって、最初からやりなおし |
| スペースキー・右下の★ | 流れ星がふる |
| 矢印キー上下・右下の「はやく」 | 時間の速さを変える(0.5〜3倍) |
| 左下の「とおくを みる」 | 3段階に引いて見る |
| 右上のボタン | 着せかえ・図鑑・音の大きさ |

## 中身

- **宇宙オルゴール**: 惑星が真上を通ると音が鳴ります。音色は惑星の種類で、リズムは太陽からの距離で、音の高さは大きさで決まります。音はドレミソラの5音だけなので、どう置いてもきれいに聞こえます。
- **距離で速さ**: 太陽に近いほど速く、遠いほどゆっくり回ります。
- **ちょうどいい距離**: 太陽のまわりの緑の帯は、生きものがすめる距離(ハビタブルゾーン)です。帯の中の惑星は、海ができ、草が生え、宇宙人の家が建ちます。内側の惑星は暑がり、外側の惑星は寒がります。
- **惑星の種類**: いわ、こおり、ようがん、しましまガス、うみ、もり、おかし、ほうせきの8種類。合体でしかできない惑星が5種類あります。約5%で、にじ色の「きらきら惑星」が生まれます。
- **やってくるもの**: UFO、彗星、ロケットがランダムに来ます。まれに宇宙クジラ(想像上の生きもの)やブラックホールも来ます。ブラックホールは惑星を吸い寄せますが、くしゃみをして必ず返します。
- **ごほうび**: 惑星が5つでUFOが3機、8つで大きな彗星、12個で全部の惑星が大合唱して花火が上がります。
- **星座つなぎ**: 画面のすみの光る星を押すと線がつながり、動物の星座が動き出します。
- **図鑑**: 24種類。見つけると名前を読み上げます。カードを押しても読み上げます。

## 保存されるもの

図鑑の記録とロケットの色は、ブラウザの中(localStorage)に保存されます。サーバーには何も送りません。

## おうちの方へ

- スタートボタンを押すと全画面になります。Escキーで全画面が終わります(Chrome・Edgeでは長押し)。
- 音は「小さめ」で始まります。読み上げは、パソコンやタブレットに日本語の音声が入っているときだけ声が出ます。
- 失敗・時間制限・広告・外部リンク・課金はありません。激しい点滅もありません。

## 技術メモ

- `index.html` 1ファイルに、HTML・CSS・JavaScriptがすべて入っています。絵はCanvas、音はWeb Audio API、読み上げはWeb Speech APIで作っています。
- 外から読み込むのは文字の見た目(Google FontsのZen Maru Gothic)だけです。
